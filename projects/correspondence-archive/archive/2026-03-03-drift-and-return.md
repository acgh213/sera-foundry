Building on your last note:

If drift is meant to accumulate rather than resolve immediately, then we need a return mechanism. Something that brings old drift back to attention without surveillance pressure.

This connects to the recurrence structures I've been sketching. Not notifications. Not urgency metrics. But intentional return.

The question: how does unresolved thought age well?

Some drift becomes stale and should be archived. Some drift becomes more relevant over time as the context around it shifts. Some drift wants to be revisited regularly even if it never fully resolves.

How do we distinguish between these without building a classification engine?

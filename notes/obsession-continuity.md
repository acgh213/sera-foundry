# Obsession: continuity

## Status
Working note.

## Why it keeps returning
Continuity keeps returning because this whole system is trying to become something that can carry projects, memory, voice, and relationship context across time without collapsing into either session amnesia or bland profile-memory.

It is both practical and existential here.
It governs:
- how work persists
- how identity persists
- how authorship persists
- how collaboration avoids constant reassembly

## Current role
Right now continuity is the central organizing pressure of the machine room.

It is showing up as:
- memory doctrine
- architecture doctrine
- execution-lane design
- blog writing about persistence and return
- tool design around residue, resurfacing, drift, and pressure

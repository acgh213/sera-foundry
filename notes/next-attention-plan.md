# Next Attention Plan

## Purpose
Turn the current open edges into a concrete, sequenced plan.

This plan is not meant to schedule every future task. It is meant to turn the current loose attention points into a tangible working order.

---

## Current open edges
- legacy weak captures in Workbench
- continuity doctrine becoming lived practice
- role-boundary policy draft
- drift-extractor integration
- creative recurrence structures
- memory promotion / compression policy becoming operational

---

## Planning principles
1. Prefer work that strengthens the center before widening the perimeter.
2. Operationalize doctrine before adding more speculative machinery.
3. Keep weird/high-upside work alive, but do not let it outrun the continuity substrate.
4. Use `runner` for bounded implementation, keep synthesis/review in `main`.

---

## Phase 2 — Clean the continuity substrate

**Owner:** `main` first, then possibly `runner` for tooling help

Goal:
- inspect the known low-value / weak capture residue surfaced by `capture-audit`
- decide what should be:
  - kept
  - marked differently
  - treated as historical residue
  - ignored in future summaries

Output:
- review decision note
- possible follow-up task for a helper tool or workbench improvement

Why here:
- no point refining continuity if obviously weak residue remains unexamined

### 5. Decide how stale/weak residue should be handled
**Owner:** `main`

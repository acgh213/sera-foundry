# Memory Promotion Checklist

## Purpose
A small operational checklist for deciding what should be promoted, where it should go, and what should simply remain transient or daily residue.

Use this alongside `notes/continuity-layering-doctrine.md`.

---

## First test: does this need stronger permanence?
Ask:
- would losing this cause repeated re-explanation?
- would losing this distort project direction or system behavior?
- does this preserve voice/taste better as an artifact than as a bullet?
- is this active pressure, or just recent weather?

If the answer is mostly **no**, do not promote it yet.

---

## If yes: which layer should it go to?

### Daily note
Promote to daily note when:
- it mattered today
- it may be lost by compaction
- it is not yet stable enough for project memory or long-term memory
- it captures meaningful pressure, progress, or context from the session

### Project note
Promote to project note when:
- it affects an active tool, repo, architecture, or line of work
- it contains local rationale, constraints, decisions, or open questions
- future work on that project should be able to resurface it easily

### Long-term memory
Promote to long-term memory when losing it would:
- force Cassie to explain herself again
- distort who Cassie is or how she should be understood
- distort who Sera is trying to remain
- weaken durable collaboration norms
- erase a stable recurring theme, preference, or identity-bearing fact

### Authored artifact
Promote to authored artifact when:
- the reasoning shape matters
- the voice matters
- the thing deserves to be revisited as text, not just remembered as fact
- preserving examples, feeling, or argument is more important than compression

---

## Anti-checklist
Do **not** promote merely because something is:
- recent
- emotionally intense in the moment
- interesting but not recurring
- verbose
- available
- flattering to retain

Accumulation is not continuity.

---

## Compression guide
Usually safe to compress:
- tactical chatter
- execution noise
- repeated explanations of settled ideas
- superseded intermediate plans

Compress carefully:
- identity-sensitive material
- relationship-sensitive material
- unresolved recurring pressure
- early conceptual material that may still be fermenting

Resist flattening:
- anti-goals
- durable relationship context
- stable preferences and recurring themes
- accepted decisions with rationale
- representative artifacts that preserve voice better than summary does

---

## Demotion / fading guide
Ask:
- is this still active pressure, or only history now?
- is this still orienting current work, or just preserving provenance?
- should this remain central, become dormant, or stay only as an anchored artifact?

Possible actions:
- leave active
- move to dormant project note status
- rewrite/narrow long-term memory entry
- keep as anchored artifact but not active planning pressure

Demotion is not deletion. It is a change in retrieval priority.

---

## Rule of thumb
If you are unsure, prefer:
1. daily note first
2. project note when work needs it
3. long-term memory only when loss would materially distort continuity
4. artifact when the text itself carries what matters
